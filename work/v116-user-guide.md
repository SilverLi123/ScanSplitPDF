# ScanSplitPDF 1.16.0 使用说明

本版新增末页右下角单位扫描。运行 `ScanSplitPDF.exe`，保留旁边整个 `_internal` 目录，无需安装Python，全程本地离线。

1. 导入扫描PDF，点击“开始自动分析”。程序整理方向、空白和拆分；明确空白默认仅从输出删除，原件不变。
2. 先处理检查中心的方向和文件交界问题。分组不可靠时暂不命名；最后一处交界确认后自动继续。
3. 在右侧名称卡片检查标题、填报单位与最终文件名。有明确“填报单位”标签时优先用标签。
4. 没有明确标签但在末页右下角找到单位时，会自动填入并标注“末页右下角落款”“需要确认”。点击“查看来源”或检查中心的单位问题，跳到对应原页并框出文字区域。核对后点“确认”；不对就修改或从候选中选择。
5. 全部必要事项确认后，点击顶部固定的“导出”。原页内容直接复制并验证，保留源文件。

末尾已删除空白不作为扫描末页；程序读取最后一张实际保留内容页，采用已确认方向。单页文件也会扫描右下角。重新识别保护人工填写/确认的名称。

落款不一定就是填报单位，因此无标签候选不自动确认。OCR未读到、单位位置不在该区域、文字模糊或候选冲突时仍需按原件核对。该版本没有更换模型，也不保证所有单位均能识别；关闭前完成导出，当前不支持关闭后恢复项目。

本版独立目录为 `D:/ScanSplitPDF-Reliable-1.16.0`。请从该目录启动新版；旧包保留，不会强制关闭其他版本的未完成会话。
