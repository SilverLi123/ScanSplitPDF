# v1.14.0 自动整理交付报告

日期：2026-10-12。开发分支 `codex/reliable-scansplit`，基线 `8b57298`（v1.13.0，321 项测试）。

## 本轮结果

一次自动分析现在能够连续完成方向检查、页码/空白联合拆分和可靠分组的名称提取。清晰结果直接进入名称卡片；处理完最后一个待确认交界后自动继续识别名称。用户仍需检查名称并明确点击导出。

这轮减少了清晰样本的重复确认和重复点击，但还没有达到真实混合业务件普遍只需少量确认的目标。

## 修改内容与可靠性保护

- 四方向 OCR 证据完整、当前横排文字充分且其他方向没有竞争时，认可保持当前 0°。预览明确显示“规则检查通过”；非零旋转仍需确认，不冒称人工决定。
- 不可靠页码追加 2400px 页眉/页脚局部识别，复用现有本地引擎、模型和严格页码阈值。候选冲突、低分或缺失继续待确认；空结果不缓存。
- 拆分前检查相邻可靠页码序列。矛盾会阻止自动拆分；裸数字重启需要前后连续序列支持，避免将表格底部数字当页码。明确“第 N 页 / Page N”可独立判断，不强制同时出现空白页。
- 只有边界、方向可靠且分析未过期的分组自动命名；部分分组命名不冒称全部完成。人工方向、边界、标题和填报单位优先；取消或异常回滚。
- 空白页默认保留，原页去向仍受完整性检查约束。OCR 引擎/模型、字段与命名算法、旧空白检测/上下文、方向算法、导出和保真算法文件相对基线没有变化。

## 测试与真实 OCR 验收

覆盖：正放认可及拒绝条件、非零旋转保护、局部坐标/缓存/冲突/取消、序列矛盾/裸数字/人工边界、可靠分组命名/人工保护/事务回滚、最后交界继续命名、直接进入名称卡片、自动与人工状态区分。旧流程测试原本强制弹出方向审核；改为验证可靠正放直接推进，同时增加“无人工方向/边界修改、无旋转建议”的断言，原有无损导出和源文件哈希断言保留。

另加 4 页真实 OCR 方向负例：0°/90°/180°/270°。三张非零方向页仍待确认，没有自动应用非零旋转。总共 20 页验收耗时 46.7 秒；当时存在其他后台工作，这不是性能基准。前三个清晰案例采用英语印刷页码，不能据此声称中文页码准确率提升；中文弱页脚局部重试后仍不够可靠。

历史提供的 11 页测试文件另做只读诊断：49.45 秒、原件不变、11 页全部保留；3 页方向和 5 处交界待确认，自动命名 0 份。尚无已核实的业务边界标注，因此仅作诊断，不计正确率。
