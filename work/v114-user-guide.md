# ScanSplitPDF 1.14 使用说明

双击完整目录中的 `ScanSplitPDF.exe`。所有识别在本机离线完成，源文件保持不变。

1. 导入 PDF，点击顶部 **“开始自动分析”**。程序检查空白、方向、文件交界；确定的分组会接着提取标题和明确的填报单位，不需要再点一次 OCR。
2. 有疑问时先看右侧 **检查中心**。方向检查只处理需要旋转或不够明确的页面；已明确正放的页面自动保持当前方向，不应用非零旋转建议。
3. 交界窗口左侧是上一内容页，右侧是可能的新首页。点“确认从这里拆分”或“属于上一份”；“稍后处理”保留问题。最后一个待确认交界解决后，程序自动更新并提取名称。
4. 拆分可靠时，自动流程直接定位 **文件名称** 卡片。核对标题、填报单位和来源；需要改字点“修改”，否则点底部 **“确认当前文件名称并看下一份”**。自动建议仍可能需要确认，找不到明确单位标签则补填。
5. 点击主窗口底部右侧 **“导出 PDF…”**，核对范围、排除页并选择目录。导出是人工启动；仍有待确认或完整性错误时不能正式导出。

页码处理按可获得证据选择：没有空白也能凭可靠页码重启拆分；有空白则比较两侧页码，连续时保留内部空白。普通数字比明确的“第N页/Page N”更容易混入表格内容，需要前后连续页码序列支持；缺失数字不会被补猜。疑难页码尝试高分辨率页边区域 OCR，但仍读不清、分数低或候选矛盾时交人工确认。

**所有空白默认保留。** 自动拆分间隔空白归前份末尾；确实无需导出的分隔空白需要单独明确排除。人工边界、方向、标题和单位不被重分析覆盖，取消或异常会回滚本轮自动整理。

本轮清晰合成样本可以直接走到名称确认，但中文短页脚尚未全部自动可靠识别；历史11页测试文件仍有方向和交界待确认。不要把“填入了名称”当作已完成复核。可用“审核全部文件交界”检查自动结果。

保留整个运行目录，不要只复制 EXE。导出复制原 PDF 页面对象，不重绘、不重压缩，并生成逐页去向 JSON。当前尚不支持关闭后恢复整理项目，关闭前完成需要导出的内容。
