交付日期：2026-10-11。源分支：codex/reliable-scansplit，基于本地 9cf5fee。原工作目录与旧版 D:/ScanSplitPDF 未覆盖，未向 GitHub 推送或发布。

## 已落实的约束

- 统一入口分析空白、方向和连续文档边界。证据不足默认保留、不拆分，集中列出待确认原因。
- 方向建议与实际方向分离。人工确认的零度方向也受保护；调整方向后使相关自动结果失效并要求重新分析。
- 单个手工拆分点不能把其他未分析页面自动变成“已确认”；没有可用 OCR 时每页都暴露归属问题。
- 分组确认在命名前完成。填报单位只使用明确标签；文头、落款、印章和正文单位不能自动替代。
- 人工标题/单位、拆开/继续、保留/排除与方向不会被重跑覆盖；边界归属改变有歧义时，保留旧人工文本为候选，要求复核。
- 导出底层强制检查分组覆盖、源文件变化及所有未确认结果。旧非严格参数和部分导出都不能绕过保护。
- 复制原 PDF 页面对象，保留原有旋转并叠加人工角度。验证内容流与图像原始编码字节、解码数据、裁切范围、比例、旋转及页面映射。临时文件校验通过后才发布，已有文件不覆盖。
- 逐页 JSON 去向记录包含已导出、人工排除、未勾选、取消和失败状态。后台取消保留已验证输出的报告；导入/分析取消回滚；关窗等待任务安全停止。

## 验收边界

当前 Windows 11 环境与合成扫描样本验证通过。尚未用用户的真实业务扫描件测量误拆、漏拆、单位识别率和人工确认量，也未在另一台干净 Windows 机器验收。本版本对证据不足的页面会增加确认次数；不得以减少提示为由降低保护或宣称所有文件完全自动正确。

页面复制及字节核对覆盖扫描件关键内容；含交互表单、签名等文件仍遵守导入时的已有提示，不能把扫描件保真验证视为交互功能或数字签名保持承诺。
