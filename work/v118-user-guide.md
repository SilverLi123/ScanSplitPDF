# ScanSplitPDF 1.18.2 使用说明

解压 `ScanSplitPDF-Reliable-1.18.2.zip`，保持整个目录完整，运行 `ScanSplitPDF.exe`。旧窗口使用旧程序，请关闭后打开新版。导出清单底部按钮固定显示，排除原页详情可滚动。

1. 导入扫描 PDF，点击“开始自动分析”。程序在本机检测空白、按现有 OCR 建议自动回正，再检查文件交界和提取可命名文件的字段。
2. 点“查看 / 调整拆分”。判断交界默认同时显示前一内容页和后一页；核对文件范围时可连续浏览整份文件，默认整页显示。
3. 想看方向结果时，点审核窗口右上角“复查自动回正”。这里显示已应用的自动建议，包括保持原方向的页面。用上一页/下一页、原页码跳转或左右键连续浏览，也可切换“原件与自动回正对照”。列表选中项、正在查看页和纠正按钮始终对应同一原页码。
4. 只有转错的页才需点“当前页向左/向右纠正 90°”。其余方向正确时，点“本批方向正确，一次确认”；不用每页确认。它只确认页面方向，拆分交界和文件名称仍分别审核。
5. 继续核对标题与填报单位，确认导出清单后无损导出。

自动回正表示采用了现有识别建议，不等于已经人工核对。低把握结果标出“重点复查”，自动回正后仍需集中确认，不能直接导出；这批方向可一次确认。没有方向建议、OCR 不可用或识别失败时，保持当前方向并提示人工处理。纸张横竖本身不能决定如何旋转。

纠正已应用的角度后，需要更新拆分与名称证据。按顶部提示继续；自动分析保留人工方向、交界、页面保留/删除和名称。重复分析不会叠加旋转。每次分析、纠正和集中确认可用“撤销上一步”或 `Ctrl+Z` 撤销。

原 PDF 不会被修改。导出复制原页，只修改输出页面 `/Rotate` 属性，继续执行保真、源文件哈希及页面去向验证。
