# v1.15 自动删除空白计划

用户指出自动化不足，并明确要求空白页删除。基线 `d4b44d5` / v1.14.0 / 366 项测试。

1. 删除输出空白与文件交界分离；明确空白经整页含页边及文本层检查后自动删除，疑似保留。原 PDF 不写入。
2. 分组使用可追踪的实际原页列表，内部删除不另起文件；人工删除/恢复、重分析及撤销保护。
3. 无页码时新增明确空白加可靠首页字段且信息变化的独立判断；缺失/低分/冲突不自动接受。
4. UI 标明自动/人工删除、输出页数、恢复入口；导出清单和逐页记录与实际映射一致。
5. 核心歧义/完整性/保真、实际 Tk 交互回归，真实 OCR 同输入比较和反例，新独立运行包自检，推送开发分支。

验收：用户不必逐页点击删除明确空白；内部空白删除不错误拆成两份；每个原页恰好有一个去向。业务准确率不以合成样本替代。当前详细结果以 [交付报告](v115-delivery-report.md) 为准。

实施完成：407项完整回归通过，20页真实OCR合成验收与历史11页只读诊断完成，原件不变、每页去向完整；运行包自检0。空白删除自动化已交付，弱中文页码/首页及真实混合件拆分确认量仍需继续优化。
