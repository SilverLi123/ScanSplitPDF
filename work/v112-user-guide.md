# ScanSplitPDF 1.12 使用说明

这是本地扫描 PDF 整理工具：分析页面并生成拆分草稿，提取标题与明确标注的填报单位，最后输出 `标题——填报单位.pdf`。源文件保持不变，处理过程不联网。

## 1. 导入与自动分析

点击“选择 PDF”，支持多选或拖入。点击顶部“开始自动分析”。顶部五步显示当前步骤和完成数量；处理时显示进度，可在进度窗口取消。完成后打开拆分检查窗口。

## 2. 检查中心

右侧“检查中心”汇总所有已导入 PDF 的待处理事项。点击事项查看原因并定位原页；双击或点“处理选中事项”打开相应检查。名称问题会切换到“文件名称”，定位对应字段；拆分尚未确认时会先要求检查拆分。

绿色表示人工确认或规则检查通过，文字明确说明来源；黄色表示需要确认；红色表示处理失败或导出阻断；灰色表示页码、保留状态等辅助信息。自动提取不等于人工确认。

## 3. 检查方向与文件交界

有方向建议时先确认方向。左边是当前生效方向，右边是待确认预览；转动右侧预览不会立即应用，点击确认后才生效。完成方向检查后程序更新拆分草稿。

交界审核左边是候选首页之前最近的内容页，右边是待判断页。中间可能跳过空白页用于比较，空白页仍保留，具体页码会显示。

- 是另一份文件的首页：点“确认从这里拆分（保留页面）”。
- 是续页、续表或附件：点“属于上一份（保留页面）”。
- 暂时拿不准：点“稍后处理此处”，问题仍待确认，稍后回来继续。
- 空白页确实无需导出：单独点击排除，并确认明确提示的原始页码。内部空白和不确定空白默认保留。

最后查看文件范围总览，核对首页和末页，可人工补拆、合并或撤销。“审核全部文件交界”也能查看规则自动建立的拆分点；没有保存的依据不会被编造为确定证据。

## 4. 确认名称

拆分确认后按顶部提示识别名称。右侧名称卡片默认显示标题、填报单位、来源和文件名预览；点击来源可核对原页，候选按需展开。

“规则检查通过 · 自动提取”是程序结果；“需要确认 · 自动建议”要求你核对；“人工确认”“人工修改”“人工选择候选”分别说明人工参与方式。旧记录无法区分时会明确说明，不猜修改历史。

需要改字点“修改”，直接输入。未找到明确填报单位时按原件填写，不用文头、落款或印章单位代替。也可分别确认标题、单位。

**名称面板底部固定显示当前文件和“确认当前文件名称并看下一份”按钮。** 核对后点击，程序定位下一份待处理文件。右侧内容可用滚轮查看，页码操作和候选默认收起。

## 5. 无损导出

**主窗口底部右侧“导出 PDF…”始终可见。** 点击后核对清单、页码范围和排除页，再选择保存位置。尚未确认的结果不能正式导出，页面完整性错误不能绕过。

检查中心区分“尚未执行预检”“预检通过”“导出后的实际校验”。文件状态改变后旧检查提示失效；取消、部分失败或尚未完成的检查不会显示为全批通过。部分清单只验证所选文件的覆盖情况。

导出复制原 PDF 页面对象，仅设置旋转属性，不重绘、不重压缩。生成逐页去向 JSON 记录。导出失败原因在检查中心和结果窗口显示，无需阅读调试日志。

## 注意

运行包包含本地 OCR 模型，请保持整个文件夹完整，不要单独移动 exe。当前会话保留人工决定，但尚不支持关闭程序后恢复整理项目；关闭前请完成需要导出的内容。界面改进不代表真实业务扫描件的自动识别准确率已经验收。
