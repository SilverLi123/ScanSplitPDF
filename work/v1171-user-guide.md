# ScanSplitPDF 1.17.1 使用说明

解压完整 ZIP 后运行 `ScanSplitPDF.exe`，保留同目录 `_internal`。流程仍是导入 → 自动分析 → 检查拆分 → 确认名称 → 无损导出。

## 检查拆分

点击顶部主要操作或“查看 / 调整拆分”。审核窗口首次默认最大化；需要时点“最大化 / 还原”，还原后的大小会记住。左侧是正在检查的文件或交界；可点“收起列表”给预览留更多空间。

文件范围总览默认打开“浏览整份文件”，并完整显示一页。交界审核默认打开“交界两页对照”，左边是交界前一内容页、右边是交界后页，两页均完整显示；需要查看正文时再切换“浏览整份文件”。

- 用“首页 / 上一页 / 下一页 / 末页”查看当前文件所有保留页面。
- 页码同时显示“第几张 / 当前共几张”和原 PDF 页码。空白排除后，原页码跳号是正常的。
- 输入原始页码并点“跳转”，或者按回车。页码不在当前文件内会提示，可切换浏览范围。
- 默认“整页”看完整页面；需要阅读小字时再选“按宽度”或放大；“+ / −”缩放。普通滚轮上下浏览，Ctrl+滚轮缩放，Shift+滚轮横向滚动，也可以拖动页面平移。翻页保留当前缩放方式。
- 需要查看被排除的空白页或前后文件时，切换到“原 PDF 全部页（含排除页）”。这只改变浏览范围，不恢复删除页、不确认拆分。

“首页与末页对照”保留快速检查入口；在交界模式，它显示“交界两页对照”。前一页会跳过明确空白和排除页，实际页码明确标注；核对这些空白可切换原 PDF 全部页。

交界判断按钮写明“确认从原第 N 页拆分”。即使你翻到其他页，决定仍针对这个交界：确认拆分、属于上一份，或者稍后处理。**查看页面不等于确认。** 下方判断依据可滚动阅读。

文件范围总览中，范围正确点“这份的页码范围正确”；误拆点“与上一份合并”。漏拆时浏览到第二份文件的首页，再点“以正在查看的页另起一份”，也可在下方输入原页码。只能在当前文件内部的保留页补拆，排除页和其他文件页会被拒绝。决定可用“撤销上一步”恢复。

## 方向与名称

检查中心的待确认方向也打开大图审核窗口。左/右转按钮只调整预览，点“方向正确，确认下一页”才生效；还可切换当前与预览方向对照。需要看另一张待确认方向页，在左侧列表选择。

拆分检查完成后继续确认名称。填报单位明确标签优先，末页右下角无标签落款仍需核对来源后确认或修改。人工名称受保护。

## 导出与保留

完成未确认项后，在主界面底部点“导出 PDF…”。原文件始终保留；输出仍复制原页面并进行完整性、保真和原件校验。

关闭审核窗口不会确认未处理问题。窗口尺寸可记住，但当前版本仍不支持关闭整个程序后恢复整理项目，请完成整理并导出后再关闭软件。
