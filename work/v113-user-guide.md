# ScanSplitPDF 1.13 使用说明

双击完整运行目录中的 `ScanSplitPDF.exe`。处理全程离线，源文件不变，导出为 `标题——填报单位.pdf`。

1. **导入**：选择或拖入 PDF，再点顶部“开始自动分析”。进度显示当前工作，支持取消。
2. **检查拆分**：右侧检查中心显示待确认方向和交界。先确认方向，程序更新拆分草稿；交界窗口左边为上一内容页，右边为可能的新首页，页号对应原 PDF，中间空白仍保留。
3. **处理异常**：确定是新文件点“确认从这里拆分（保留页面）”；确定为续页点“属于上一份（保留页面）”；拿不准点“稍后处理此处”，问题仍在清单内。范围总览可检查每份首页末页，“审核全部文件交界”可复查自动拆分。
4. **确认名称**：按顶部提示识别名称，在右侧“文件名称”卡片核对标题和明确填报单位；需改字点“修改”。底部固定“确认当前文件名称并看下一份”。没有填报单位标签时需要人工补录，不能用文头或落款替代。
5. **导出**：主窗口底部右侧“导出 PDF…”打开清单与保存位置。待确认或页面完整性错误会阻止正式导出；成功后核对实际保真校验和逐页去向 JSON。

## 本轮拆分变化

空白页不是必要条件，程序按可获得的证据判断：

| 情况 | 程序处理 |
| --- | --- |
| 可靠印刷页码 2 → 1，无空白、同一表名 | 无矛盾时自动从后一页拆分 |
| 可靠页码 2 → 空白 → 1 | 无矛盾时拆分；空白留在前份末尾 |
| 可靠页码 1 → 空白 → 2 | 保留为同一份文件的内部空白 |
| 页码跳号、读不清或候选冲突 | 待确认，不自动拆 |
| 重新从 1 开始，但标有续表/附件或前份总页数未到末页 | 待确认，不猜文件归属 |
| 无空白连续两个第 1 页，前份总页数未知 | 待确认，不能确定两份单页文件 |

标题及填报单位用于辅助和检查矛盾，不要求每个文件同时有标题变化和空白。自动交界显示实际保存的“原页号、印刷页码变化、保留空白及原因”。“规则自动建立”与“人工确认”分别标注。

部分中文短页脚虽然能读出页码，识别分数仍不足，程序会要求确认；不把 OCR 分数当作正确率。无法判断时人工确认是必要操作。

所有空白默认保留，包括分隔间隔。确实要排除时单独操作，并核对提示的原始页码。重新分析不会覆盖人工边界、方向、标题和单位；撤销保留证据快照。

请保留整个运行文件夹，不能只复制 EXE。当前仅在会话内保留整理状态，尚不支持关闭后恢复项目；关闭前完成导出。合成测试不能代替用户真实业务文件验收。
