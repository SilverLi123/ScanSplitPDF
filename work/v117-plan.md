# v1.17 审核窗口与整份文件浏览

日期：2026-10-12。基线 `9ccb780`（v1.16.0，438项）；分支 `codex/reliable-scansplit`。

用户要求：待确认窗口打开即可看清，拆分后能浏览正在审核文件的全部页面，并改善操作细节。沿用 Tk，不修改 OCR、拆分、命名或导出算法。

原界面由 `ReviewDialog` 左侧待办列表、右侧两页预览、底部决定组成。不同模式只展示当前/建议方向、交界两侧或分组首页/末页；窗口默认固定初始大小。查看其他页依赖回到主界面，长说明与较宽工具栏容易挤压预览或按钮。

实施：

1. 默认最大化，记住还原窗口尺寸；按父窗口所在屏幕工作区限制恢复位置与最小尺寸。
2. 审核窗口内加入整份文件分页浏览，显示当前序号与原页码，支持跳转、整页/宽度适配、缩放、滚动、平移。
3. 保留两页对照页签；当前草稿默认仅浏览实际保留页，也可切换原 PDF 全部页检查排除页。
4. 浏览页与审核目标分离。方向只预览待确认页，不应用建议；翻页与导航不确认、不改变分组或删除状态。
5. 支持以正在查看的保留页补拆，限制当前文件内部；沿用既有人工边界与撤销操作。
6. 控件固定在底部、依据独立滚动、列表可收起。小屏/较高系统缩放时压缩重复提示并按可用宽度排列决定。
7. 实际 Tk 回归、原件与状态只读断言、三个窗口尺寸的合成审核截图；完整 pytest 后构建独立新版包并自检。

验收以真实控件可见性、状态保护和原页可达性为准。合成 UI 场景不作为拆分准确率验收；本轮不重复宣称 OCR 或业务识别能力有所提升。
