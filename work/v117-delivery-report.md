# v1.17.0 审核体验交付报告

日期：2026-10-12。分支 `codex/reliable-scansplit`；基线 `9ccb780`（v1.16.0，438项）。

## 修改前的问题

审核窗口打开后仍需手动放大；分组只展示首页与末页，不能在同一窗口连续检查正文；翻阅原件与决定交界缺少清楚区分。长依据、较宽列表和高系统缩放容易挤压预览；检查中心方向问题进入另一种小型列表窗口。

## 本轮修改

- 默认最大化，记住还原大小，在父窗口屏幕工作区内恢复，保留系统最大化/还原按钮。
- 默认提供整份文件浏览页签，首页/上一页/下一页/末页、原页码跳转、整页/宽度适配及缩放；滚轮/快捷键与平移可直接使用。
- 当前草稿显示实际保留页；另提供原 PDF 全部页范围，排除页仍可核对。首页/末页、交界两页对照保留为辅助页签。
- 确认目标与当前浏览页分离，交界按钮显示实际目标原页码；方向旋转仍只是草稿，确认后才生效。查看、切换范围、跳过、关闭都不能隐式确认。
- 查看到漏拆位置可直接另起一份，限制当前文件内部保留页，并沿用原人工决定/撤销路径。
- 列表可收起；长依据独立滚动；底部决定固定可见，按可用宽度排列；小窗口压缩重复说明。检查中心方向入口统一大图审核。
- 预览与缩略图显式绑定所属 Tk 解释器，防止多个窗口/测试根窗口时图片绑定到旧解释器。

修改集中于 `review_ui.py`、`ui.py`、`ui_widgets.py` 和版本号。没有修改 OCR 引擎/模型、拆分规则、命名规则、导出及保真验证算法。

## 用户流程变化

旧：自动分析 → 看首页/末页 → 回到主窗口查中间页 → 返回确认。

新：自动分析 → 在同一大窗口翻阅当前文件全部页 → 必要时对照交界或查看排除页 → 明确确认 → 名称 → 主界面导出。
