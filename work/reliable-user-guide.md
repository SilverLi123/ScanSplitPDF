# ScanSplitPDF 1.10.0 使用说明

目标：处理混合扫描 PDF，按“标题——填报单位.pdf”拆分命名，全程本地离线。可靠性优先；识别结果不确定时停在待确认状态。

## 操作流程

1. 打开 PDF，可多选或拖入。批量读取和分析在后台运行，可取消。
2. 点击“自动拆分”。系统检查空白、方向、页码、标题和填报单位变化。
3. 检查方向与拆分。方向建议不会直接生效；支持逐页预览、选择旋转角度，或检查后批量保持当前方向。方向改变后重新自动拆分。
4. 点击“检查拆分”处理待确认边界。“保留页面并拆开”不删除页；“继续同一份”合并；“确认并排除分隔空白”会明确询问是否排除空白页。
5. 分组确认后点击“OCR 自动命名”。单位只使用明确的“填报单位”标签；没有标签就手填，出现多个不同值就人工裁决。点击“查看来源”可定位原页及识别区域；可直接修改或点击字段确认按钮。
6. 点击“导出全部”，检查清单并勾选要导出的文件。未确认的边界、方向、名称会阻止正式导出。

## 可靠性保护

- 原 PDF 仅读取；导出复制原页面对象，旋转只写入 /Rotate，不重绘或压缩扫描图。
- 原文件变化、分组重叠、无依据排除、未确认方向或边界会被底层导出检查阻止。
- 已人工决定的拆分、保留/排除、方向、标题和单位受保护。边界改变后无法确定旧名称归属时，原人工名称保留为候选并要求复核。
- 导出前后检查源文件 SHA-256；每份输出检查内容流、嵌入图像、裁切尺寸、旋转和页面映射。未通过校验的临时文件不会发布。
- 同名输出自动加编号，不覆盖已有文件。取消时保留已验证完成的文件，并记录哪些页尚未导出。
- 输出目录同时生成 ScanSplit-导出记录-*.json，逐页记录导出文件及页码、人工排除页、未勾选页和取消/失败状态。
- 方向/名称评分是规则和 OCR 证据分数，不是正确率承诺。模糊、手写、特殊版式仍需人工核对。

## 版本与验收范围

本版本从本地 9cf5fee 基础开发，源码位于 codex/reliable-scansplit 分支，没有覆盖原工作目录或发布到 GitHub main。

已设计回归验证覆盖页面完整性、人工保护、重新分析、旋转、取消、部分导出、无损复制及 120 页文件。混合扫描验收脚本同时记录自动建议与按样本真值模拟的人工确认，二者分开统计。真实业务扫描件尚未完成验收，因此不把合成样本结果当作所有真实文件的自动正确率。

运行打包版无需安装 Python。整个 ScanSplitPDF 文件夹需保持完整，双击 ScanSplitPDF.exe；不要只复制 exe。模型已随包附带，运行无需联网。
