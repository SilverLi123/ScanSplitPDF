# ScanSplitPDF 1.11.0 流程与界面交付报告

本轮针对“自动拆分后不知道怎么使用、UI 交互不够清楚”改进既有 Windows 离线工具。运行目录为 `D:\ScanSplitPDF-Reliable-1.11.0`，独立于 1.10.0 和原工作目录。

## 已交付的行为

- 顶部五步流程按实际状态显示当前步骤，并只强调一个下一步动作。命名入口在文档边界和方向未确认时置灰，多文件全部完成拆分检查后才命名。
- 自动拆分主流程完成后打开引导检查窗口。页面方向先确认，旋转按钮仅调整预览；点击确认才写入人工方向。最后一个方向问题处理后自动后台更新拆分。失败/取消保留人工方向，并提示继续更新。
- 拆分复核并排显示前后内容页，问题直接说明“是否从原第 N 页开始一份新文件”。“这里开始新文件”和“属于上一份”都保留页面。中间空白页保留状态明确显示，排除需要单独确认页码。
- 待处理事项逐项推进，可返回主界面稍后处理；未处理事项不会被当成已确认。拆分总览可核对首页/末页、人工补拆、合并和撤销。
- 未确认分组隐藏名称编辑。命名支持逐份确认并定位下一份，候选和来源按需展开，清空字段会重新待确认。右侧鼠标滚轮可滚动，无需把指针移动到滚动条。
- 常用操作精简，其他操作和处理记录收起。导出先检查清单，再选择保存位置。
- 修复极快的后台任务完成后仍被标为忙碌的竞争问题。复核窗口在 960×640 可见决策按钮，左右预览等宽，默认适合窗口；主界面在 1100×680 保留名称编辑宽度。

## 使用与验证范围

首次打开选择 PDF，按顶部主要按钮继续，无需自行记住方向确认后再次分析。详细逐步说明见包内“使用说明.md”。“稍后处理”在当前打开会话内保留决定，尚不提供关闭程序后恢复的项目保存功能。

原识别算法、人工优先和导出完整性保护继续保留。本轮验证使用合成样例，用户真实业务扫描件和另一台干净 Windows 机器尚未验收。实际识别准确率、需要确认多少次，以及用户对这套新交互是否顺手，仍应结合真实使用判断。
