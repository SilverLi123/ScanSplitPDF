# ScanSplitPDF 1.15 使用说明

启动 `ScanSplitPDF.exe`，导入扫描 PDF，点击顶部“开始自动分析”。软件在本机检查页面、方向、交界，删除明确空白并为可靠分组提取标题和填报单位；原 PDF 保持不变。

## 空白页默认怎么处理

- **明确空白**：通过整页含页边复核、没有文本层，默认不进入导出文件。缩略图显示“明确空白 · 自动删除”。首尾、分隔、文档内部的明确空白都适用。
- **疑似空白**：有可能含页码、印章、签名，或检查没有通过，先保留。检查中心提示“疑似空白，已保留”，点击查看原页。
- **人工决定**：右键缩略图，可选择“恢复选中页（保留到输出）”或“删除选中页（仅输出，不改变交界）”。删除需明确确认；可以撤销。再次自动分析不会覆盖人工保留或删除。

删除空白与拆开文件是两件事。例如原第1页、空白第2页、第3页是同一文件，导出两页，原第3页成为输出第2页；不会因为删空白就另生成一个文件。

## 处理异常与名称

右侧检查中心显示方向、交界和名称问题。交界窗口比较的是“前一内容页”和“后一内容页”，按原始页号显示；中间有空白时也会说明。

如果右页是新文件首页，选择确认拆分；如果是续页，选择属于上一份。这个决定不会恢复已自动删除的空白。若确实需保留空白，单独右键恢复该页。

可靠分组会自动填入名称卡片；标题/填报单位分别显示来源及规则通过、自动建议或人工修改。核对最终 `标题——填报单位.pdf` 后确认。名字缺失时补填；多个候选冲突时按原件选择。

## 导出

处理完待确认方向、交界和名称，点击“查看清单并导出”。清单显示原始范围、实际输出页数和删除页；名称卡片也会说明输出页数。

导出复制原 PDF 的内容与图像，仅通过 `/Rotate` 设置已确认方向，不重绘、不重编码。页面完整性、映射、保真和原文件 SHA-256 检查不能跳过。

每次导出生成逐页 JSON 记录：`exported` 为已导出，`excluded_blank_rule` 为规则自动删除明确空白，`excluded_manual` 为人工删除。记录原页号、输出页号和删除依据，删除页不记入任何输出文件。

全为空白的文件不会生成空 PDF；软件提示没有可导出的内容页，仍可从缩略图恢复原页。

## 当前自动化边界

清晰页码可以自动拆分；明确空白不再逐页要求删除确认。无页码时也有独立首页证据规则，但实际中文字段低分仍可能要求确认。机器读出了字，不等于文件归属可靠。

真实混合业务件的准确率、几百页使用体验尚未完整验收；当前没有关闭后恢复整理项目的功能。先保留原扫描件和导出记录。
