# ScanSplitPDF 1.11.1 布局与导出入口交付报告

针对中间预览占比过大、两侧信息被压缩、导出按钮不易发现的问题，调整既有 Windows 离线工具。运行目录为 `D:\ScanSplitPDF-Reliable-1.11.1`，保留旧版目录。

## 本轮改动

- 主窗口三栏按窗口宽度分配：正常宽度下左侧约 24%、中间约 32%、右侧约 44%；较小窗口保留左右最小宽度。分隔线仍可拖动。
- 左侧文件列表支持横向滚动，下方显示当前文件完整名称。右侧页码、确认状态、字段提示和文件名随栏宽换行；页码导航按钮缩短，避免横向挤压。
- “导出 PDF…”使用醒目的主按钮样式，固定在窗口底部右侧。旁边显示已确认份数和剩余待检查份数，处理期间暂时禁用。
- 导出仍先展示清单，拆分、方向或名称未确认时不能正式导出。按钮可见不代表已经满足导出要求；未改变人工决定、OCR 和无损导出逻辑。
- 文件交界检查窗口加宽左侧问题列表，并让页码说明随宽度换行。

## 使用与限制

按顶部主要按钮完成导入、自动拆分、检查拆分和检查名称，最后点击**窗口底部右侧“导出 PDF…”**。右侧内容较长时用滚轮向下查看，三栏间分隔线可自行拖动。

请保持整个运行文件夹完整，不要单独移动 exe。真实业务扫描件的识别准确率与另一台干净 Windows 机器尚未验收；本轮结果不能作为完全自动拆分正确率。会话恢复功能仍未提供，关闭前应完成需要导出的文件。
