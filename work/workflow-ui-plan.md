# 1.11.0 使用流程与交互改进

用户反馈：自动拆分后完全不知道如何使用；确认入口和页面证据分散，交互需要优化。授权范围是改善当前 Windows 离线工具并交付运行包。

采用现有 Tk 原生控件，保留可靠性机制。五步导入→自动拆分→检查拆分→检查名称→导出，顶部只强调一个当前主要动作。复核窗口按方向→更新分析→不确定交界→分组总览推进；页面证据并排展示，按钮直接回答文件归属，不默认替用户作决定。转动仅预览，明确确认才生效，最后一页方向确认后自动重新分析。待确认允许暂留。总览支持补拆/合并，不删除内容页。

命名前隐藏未确认分组的字段。命名阶段直接编辑并确认一份、跳到下一份；来源和候选仍可查看。处理记录默认收起，导出先清单后保存位置。

验证：补充分步状态、多文件顺序、预览不改变原状态、方向后的重分析/取消、拆分保留、补拆/合并、命名跳转测试；跑原回归；检查真实 Tk 界面的初始/检查/命名窗口和小屏尺寸；打包 1.11.0 后自检及 ZIP 校验。

真实业务文件准确率仍待实际样本验收；本轮不改变识别算法和无损导出实现。
