# ScanSplitPDF 1.11.0 使用说明

打开 `ScanSplitPDF.exe`，按窗口顶部的大按钮往下走。顶部五个步骤会标出当前的位置；大按钮始终告诉你接下来做什么。

## 1. 导入 → 自动拆分

点击“选择 PDF”，也可多选或直接拖入。导入完成后点击“开始自动拆分”。结果是草稿，不会立即写入文件。处理完成后自动打开检查窗口。

## 2. 在检查窗口完成方向和拆分

**有方向问题时先把页面转正。** 左边是当前方向，右边是待确认的预览。“向左转 / 向右转”和“预览建议方向”只改变右边的预览。看清文字正向后点击“方向正确，确认下一页”。最后一个方向问题确认完，程序自动更新拆分结果。关闭或取消时，未完成的检查仍保留。

**有文件交界问题时，直接比较两页。** 问题“是否从原第 6 页开始一份新文件？”表示判断第 6 页是不是另一份文件的首页。

| 你看到的情况 | 点击 |
|---|---|
| 右边是另一份文件的首页 | 这里开始新文件（保留页面） |
| 右边是左边文件的续页、续表或附件 | 属于上一份（保留页面） |
| 中间空白页确实用于分隔两份文件，并且不需要导出 | 排除已确认的分隔空白，再确认明确提示的页码 |

内部空白页应保留；拿不准时不要排除。查看前后内容页时，中间空白页不会因此被删除。一次决定后自动显示下一处问题。

**最后查看拆分总览。** 每份文件显示原始页码范围，并排展示首页和末页。范围正确就继续；需要人工确认的范围点“这份的页码范围正确”。发现漏拆，在下方输入第二份文件的原始首页，点“从这页另起一份”；发现误拆，选后一份点“与上一份合并”。决定可用“撤销上一步”恢复。

点“检查完成，继续下一步”。还有其他 PDF 待检查时会先处理它；全部拆分确认后才进入识别名称。拿不准时可点“稍后处理 / 返回主界面”，稍后再检查。

## 3. 检查名称

程序提取标题和明确标注的填报单位。右侧每份文件的两个输入框都可以直接修改。没有找到填报单位时需要按原件填写，不用文头或落款单位替代。

点“查看候选与识别来源”可以展开候选列表，再点“查看来源”定位证据。核对完点“确认本份名称并看下一份”，程序会定位下一份待处理文件。也可以只确认某一个字段。清空字段会重新进入待确认状态。

右侧面板支持滚轮；中间原页预览支持放大和拖动。顶部主按钮可定位待确认名称。

## 4. 导出

点“查看清单并导出”，先核对文件名、页码范围和排除页，再选择保存位置。待确认的拆分、方向、名称不能正式导出。重名输出加编号，已有文件和源文件不会被覆盖。

导出复制原 PDF 页面对象，只写入旋转属性，不重绘、不重压缩图片。同时检查页面完整性和原文件 SHA-256，生成逐页去向 JSON 记录。

## 其他操作与限制

顶部“更多操作”中提供撤销、重新检查方向、命名格式、使用帮助和处理记录。记录默认收起。

“稍后处理”保留的是当前打开会话内的决定，不代表已经保存为可下次恢复的项目。关闭程序前请完成需要导出的文件。

运行包包含本地 OCR 模型，无需联网或安装 Python。请保持整个程序文件夹完整，不要只复制 exe。真实业务扫描件的识别准确率尚未验收；模糊、手写、复杂版式仍需核对。使用流程简化没有取消可靠性检查。
